Using these decks in class
  • → / Space — next step or next slide  ·  ← — go back
  • m — jump to any slide  ·  f — fullscreen  ·  Home / End — first / last slide
  • Every question appears in three steps: the question, then "Are you ready for the answer?", then the answer — so you can pause and let the class attempt it.
  • An ⓘ button next to a phrase opens a panel explaining why it is worded that way. Click-only, so it never interferes with the arrow-key stepping.
  • Swipe left / right works on a tablet.
