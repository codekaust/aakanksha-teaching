Insertion sort

Move each element left by swapping it with larger neighbours.

The program

Download .py
01def insertion_sort(list):
02    n = len(list)
03    for i in range(1, n):
04        j = i - 1
05        while j >= 0:
06            if list[j + 1] < list[j]:
07                list[j + 1], list[j] = list[j], list[j + 1]
08            j = j - 1
