Copy records with at least 90%

Write all student records to one binary file and qualifying records to a second file.

The program

Download .py
01import pickle
02while True:
03    print("1. Create binary files")
04    print("2. Display all records")
05    print("3. Display records with percentage >= 90")
06    print("4. Exit")
07    a = int(input("Enter the option from 1 to 4: "))
08    if a == 1:
09        f = open("student.dat", "wb")
10        o = open("selected.dat", "wb")
11        x = int(input("How many students? "))
12        for i in range(x):
13            name = input("Enter a name: ")
14            eng = int(input("English marks: "))
15            lang = int(input("Language marks: "))
16            eco = int(input("Economics marks: "))
17            bs = int(input("Business Studies marks: "))
18            acc = int(input("Accountancy marks: "))
19            cs = int(input("Computer Science marks: "))
20            tot = eng + lang + eco + bs + acc + cs
21            per = (tot / 600) * 100
22            t = [name, eng, lang, eco, bs, acc, cs, tot, per]
23            pickle.dump(t, f)
24            if per >= 90:
25                pickle.dump(t, o)
26        f.close()
27        o.close()
28    elif a == 2:
29        f = open("student.dat", "rb")
30        try:
31            while True:
32                p = pickle.load(f)
33                print(p)
34        except EOFError:
35            f.close()
36    elif a == 3:
37        print("Students with percentage >= 90:")
38        o = open("selected.dat", "rb")
39        try:
40            while True:
41                s = pickle.load(o)
42                print(s)
43        except EOFError:
44            o.close()
45    else:
46        break
About the notebook transcription

This follows the notebook: records are written to the second file during entry, rather than reopened and copied later. The heading says “90 and above”, so >= 90 corrects the handwritten > 90. EOFError handling is made explicit. Create the files before displaying them.

Source: supplied notebook photos 16, 18, 17, 19, 20, 21, numbered in ZIP order. Spelling, whitespace and identifier capitalisation are normalised for readable Python. Worked-output photos are not published with the exercise.
