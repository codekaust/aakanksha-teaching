Simple and compound interest

Calculate simple interest, compound interest and their difference using two functions.

The program

Download .py
01def simint(p, t, r):
02    si = float(p * t * r / 100)
03    return si
04def comint(p, t, r):
05    amt = float(p * (1 + r / 100) ** t)
06    ci = amt - p
07    return ci
08p = float(input("Enter the principal amount: "))
09t = float(input("Enter the time: "))
10r = float(input("Enter the rate of interest: "))
11si = simint(p, t, r)
12ci = comint(p, t, r)
13diff = ci - si
14print("Simple interest is Rs. %.2f" % si)
15print("Compound interest is Rs. %.2f" % ci)
16print("Difference amount is Rs. %.2f" % diff)
