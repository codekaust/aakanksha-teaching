# Learning Python — instructions

Read README.md before editing this course. The current course replaces the old hands-on
beginner lessons with the 14 supplied notebook programs and a paper-first routine.

- Give students the program and exact input, then ask for a complete handwritten trace.
- Only after teacher review should students unlock the answer, correct their trace, and
  write the program independently. Do not add quizzes, hint ladders or extra projects.
- Each program has a separate password. Never place plaintext answers, passwords, original
  worked-answer photos or private lesson sources in this repository, including tool fixtures.
- Preserve notebook algorithms and explicitly note corrections or shortened sample inputs.
- Keep explanations plain and precise: conditions, variable changes, calls, returns,
  output and file effects. Every loop iteration must be traceable; do not skip with ellipses.
- Update the private source and use tools/build.py to rebuild pages. Maintain existing
  passwords unless the teacher asks to rotate them.
- Keep shared styling in assets/day.css, relative site paths, accessible forms and
  separate printable exercise/answer layouts. No browser runner is needed.
- Verify program outputs, full trace behaviour and password protection before publishing.
