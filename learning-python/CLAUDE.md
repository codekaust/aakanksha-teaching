# Learning Python — instructions

Read `README.md` in this folder before writing or changing a day page. It holds the course
rules: **always hands-on** (slowly help the student build a program they interact with, and
learn Python by building it), never give the solution to the day's main program, use hint
ladders instead, and follow the structure of a day page.

- Create pages **one day at a time**, only when asked. Don't create future days ahead of time.
- Use `day-01.html` as the model for each new day, and add a card for the new day to `index.html`.
- Before publishing, run every "Try this" example with `python3` and check the output on the page matches.
- Address the student as "you". The student is an absolute beginner.
