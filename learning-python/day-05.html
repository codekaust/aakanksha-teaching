Count lines, words and characters

Create a text file and count its lines, whitespace-separated words and characters.

Two things to do today

  1. Run it in your head, on paper. In your notebook, write what the program does. Trace the assigned run below, one executed line at a time. Write every variable change, condition result and output. Repeat the steps for every loop iteration or function call. Show your teacher.
  2. Write the program yourself. After your teacher gives you the password, check and correct your trace. Then cover the code and write it from memory. You may run it after you finish.

The program

Download .py
01def count_text_file(file_name):
02    line_count = 0
03    word_count = 0
04    character_count = 0
05    with open(file_name, "r") as file:
06        for line in file:
07            line_count += 1
08            word_count += len(line.split())
09            character_count += len(line)
10    print("No. of lines =", line_count)
11    print("No. of words =", word_count)
12    print("No. of characters =", character_count)
13def create_text_file(file_name, content):
14    with open(file_name, "w") as file:
15        file.write(content)
16file_name = "sample.txt"
17content = "Hi Ada\nLearn Python"
18create_text_file(file_name, content)
19print("Entered content into the file:")
20print(content)
21count_text_file(file_name)
