Part 1 · Learn these 5 concepts

1Joining and measuring text

Goal: build bigger pieces of text from smaller ones.

Definition

A string (str) is a sequence of characters: letters, digits, spaces and symbols, in order. Three things you can do with strings:

  • + joins two strings into one (this is called concatenation).
  • * repeats a string a number of times.
  • len() tells you how many characters a string has.
Try thisfirst = "Punith"
last = "Kumar"
full = first + " " + last

print(full)
print("=" * 20)
print(len(full))
OutputPunith Kumar
====================
12

Notice the " " in the middle. + joins exactly what you give it and adds nothing on its own, so without that space you'd get PunithKumar.

"Punith" has 6 letters and "Kumar" has 5. Why does len(full) give 12, not 11? Answer it yourself first. Ready? Click to check.

A space is a character too. full is "Punith" + " " + "Kumar", which is 6 + 1 + 5 = 12 characters. len() counts every character, including spaces and punctuation.

2Indexing and slicing

Goal: pick out one character, or a piece, from a string.

Definition

Every character in a string has a position number called its index. Counting starts at 0, not 1. You can also count backwards from the end with negative numbers: -1 is the last character.

CharacterPYTHON
Index012345
Negative index-6-5-4-3-2-1
  • Indexing, name[3], gives one character.
  • Slicing, name[start:end], gives a piece. It starts at start and stops just before end.
  • Leave out start to begin at the start; leave out end to go to the end.

Two things that crash
  • name[6] → IndexError: string index out of range. "PYTHON" has 6 characters, so the last index is 5.
  • name[0] = "J" → TypeError: 'str' object does not support item assignment. You can't change a character inside a string. Strings are immutable, which means they can't be changed once made. To get a different string, you build a new one.

Type both and read the error messages. Learning to read errors is half of programming.

"put" is indexes 3, 4 and 5. The slice stops before the end number, so you need word[3:6].

Slicing past the end: what does "al"[0:4] give? An error? Guess, then try it. Ready? Click to check.

It gives "al", and there's no error. A slice takes whatever characters exist in that range, even if the string is shorter. Only indexing a single position that doesn't exist (like "al"[4]) crashes. Remember this. You'll need it in today's program.

3String methods

Goal: clean up and change text with ready-made tools.

Definition

A method is a function that belongs to a value. You call it with a dot: value.method(). String methods give back a new string, and they never change the original.

MethodWhat it doesExample → result
.strip()Removes spaces from both ends" hi ".strip() → "hi"
.upper()All capitals"hi".upper() → "HI"
.lower()All small letters"HI".lower() → "hi"
.title()Capital first letter of each word"new delhi".title() → "New Delhi"
.replace(a, b)Swaps every a for b"banana".replace("a", "o") → "bonono"
.count(a)How many times a appears"banana".count("a") → 3
Try thiscity = "  new delhi  "

print(city.strip())
print(city.strip().title())
print(city.upper())
Outputnew delhi
New Delhi
  NEW DELHI

The second line chains two methods: .strip() runs first and gives "new delhi", then .title() runs on that. The third line keeps the spaces, because nobody asked to strip them.

After city.upper() runs, what does print(city) show? Think about the word "immutable". Ready? Click to check.

It still shows " new delhi ", unchanged. .upper() made a new string and gave it back, but nothing stored it, so it was thrown away.

To keep the result, assign it: city = city.upper().

4f-strings: putting values inside text

Goal: mix text and values neatly, with control over decimals.

Definition

An f-string is a string with an f just before the opening quote. Anything inside { } is worked out by Python and its value is put into the text at that spot.

{value:.2f} shows a number with exactly 2 decimal places (.1f for one, and so on).

Try thisname = "Punith"
total = 77 + 64 + 80
percentage = total / 300 * 100

print(f"{name} scored {total} / 300")
print(f"Percentage: {percentage}%")
print(f"Percentage: {percentage:.2f}%")
print(f"Next year you will be {17 + 1}")
OutputPunith scored 221 / 300
Percentage: 73.66666666666667%
Percentage: 73.67%
Next year you will be 18
  • Forget the f and Python prints the braces literally: {name} scored {total} / 300. Try it.
  • You can put a calculation inside the braces, like {17 + 1}.
  • The % sits right against the number, with no extra space, because everything outside the braces is printed exactly as you typed it.
Now fix your warm-up

Go back to your Day 1 report card and change the percentage line so it always shows exactly one decimal place. Run it again with 77, 64 and 80.

Day 1's print("Percentage:", 90.0, "%") printed Percentage: 90.0 %. Why the space, and how does an f-string avoid it? Answer it yourself first. Ready? Click to check.

When you give print several values separated by commas, it puts a space between each one, so a space lands between 90.0 and %.

An f-string is one string, and you decide exactly where every character goes: print(f"Percentage: {percentage}%").

5Converting between text and numbers

Goal: know when a value is text and when it is a number, and switch between them.

Definition

Type conversion turns a value of one type into another:

  • int("2009") → 2009 (text to whole number)
  • float("5.8") → 5.8 (text to decimal)
  • str(17) → "17" (number to text)
Try this · predict each line firstyear = "2009"

print(year + "1")
print(int(year) + 1)
print(year[-2:])
Output20091
2010
09

Same year, three different results. As text, + joins and slicing picks out characters. As a number, + adds. Pick the type that fits the job: to cut digits out, keep it as text; to calculate, convert it to a number.

age = 17 then print("Age: " + age) crashes. Why? Give three different ways to fix it. Answer it yourself first. Ready? Click to check.

It crashes with TypeError: can only concatenate str (not "int") to str. + can join two strings or add two numbers, but it can't mix a string and a number.

print("Age: " + str(age))   # 1. convert the number to text
print("Age:", age)          # 2. use a comma; print handles the types
print(f"Age: {age}")        # 3. use an f-string

All three print Age: 17.

Part 2 · Today's main assignment

🎯 Project · Student ID Card Generator

Your school is printing ID cards. People type their details carelessly, with extra spaces, ALL CAPITALS and all small letters. Your program has to turn whatever they type into a clean, correct ID card.

Requirements

Your program must:

  1. Ask for the student's first name, last name, year of birth and city.
  2. Clean the names and the city: no extra spaces, and a capital first letter on each word.
  3. Show the full name and the initials (for example P.K.).
  4. Calculate the student's age in 2026.
  5. Make a username: the first 4 letters of the first name in small letters, followed by the last 2 digits of the birth year.
  6. Show how many letters are in the name (first name + last name, not counting the space).
  7. Print the card neatly, with a border line made using *.

Expected output

Look at how messy the typing is, and how clean the card still comes out:

Rules

  • Nothing on the card may be typed in by you. Every line must be worked out from what the user typed.
  • It must work for any name, year and city, however messily they're typed.
