Stack: push and pop

Add values to the end of a list and remove them in last-in, first-out order.

Two things to do today

  1. Run it in your head, on paper. In your notebook, write what the program does. Trace the assigned run below, one executed line at a time. Write every variable change, condition result and output. Repeat the steps for every loop iteration or function call. Show your teacher.
  2. Write the program yourself. After your teacher gives you the password, check and correct your trace. Then cover the code and write it from memory. You may run it after you finish.

The program

Download .py
01def push(stack, ele):
02    stack.append(ele)
03    print(ele, "pushed into the stack")
04stack = []
05print("Initially stack is empty:", stack)
06push(stack, 12)
07push(stack, 24)
08push(stack, 14)
09print("Elements in the stack now:", stack)
10print("Elements removed from the stack:")
11print(stack.pop())
12print(stack.pop())
13print(stack.pop())
14print("Contents of stack now:", stack)
About the notebook transcription
