Create and read a binary file

Store student names and six subject marks in a binary file, then read the records back.

Two things to do today

  1. Run it in your head, on paper. In your notebook, write what the program does. Trace the assigned run below, one executed line at a time. Write every variable change, condition result and output. Repeat the steps for every loop iteration or function call. Show your teacher.
  2. Write the program yourself. After your teacher gives you the password, check and correct your trace. Then cover the code and write it from memory. You may run it after you finish.

The program

Download .py
01import pickle
02while True:
03    print("1. Create a binary file")
04    print("2. Display the contents")
05    print("3. Exit")
06    a = int(input("Enter the option from 1 to 3: "))
07    if a == 1:
08        f = open("student.dat", "wb")
09        x = int(input("How many students? "))
10        for i in range(x):
11            name = input("Enter the name: ")
12            eng = int(input("English marks: "))
13            lang = int(input("Language marks: "))
14            eco = int(input("Economics marks: "))
15            bs = int(input("Business Studies marks: "))
16            acc = int(input("Accountancy marks: "))
17            cs = int(input("Computer Science marks: "))
18            t = [name, eng, lang, eco, bs, acc, cs]
19            pickle.dump(t, f)
20        f.close()
21    elif a == 2:
22        f = open("student.dat", "rb")
23        try:
24            while True:
25                p = pickle.load(f)
26                print(p)
27        except EOFError:
28            f.close()
29    else:
30        break
About the notebook transcription

Create the file before choosing Display. The notebook’s bare except is narrowed to EOFError so an unrelated error is not hidden. The file closes after the entire writing loop. Use only binary files created by this program.
