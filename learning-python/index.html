Learning Python

Python from the very first line. Each day, you learn a few ideas by typing and running them, then use them together to build a program you can actually use.

How every day works
  1. Learn: a few short concepts, each with code to type and run yourself.
  2. Check: a question after each concept. Answer it first, then reveal the answer.
  3. Build: one program that uses everything from the day. You write it; hints help if you get stuck, but no solution is given.
  4. Explain: record a short video explaining your program, then submit it with your code.
