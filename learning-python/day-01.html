Part 1 · Learn these 5 concepts

1Printing output: print()

Goal: understand how Python displays information.

Definition

print() is a function: a ready-made instruction that Python already knows. Whatever you put inside its brackets gets shown on the screen.

  • Text goes inside quotation marks: "Hello" or 'Hello'. The quotes tell Python "this is text, show it exactly as written."
  • Numbers and calculations are written without quotes, so Python works them out first.
  • Several values can be printed at once if you separate them with commas. Python puts a space between them: print("Age:", 17) → Age: 17
Try thisprint("Hello World!")
print("My name is Punith")
print(10 + 20)
OutputHello World!
My name is Punith
30
Why does print("10 + 20") behave differently from print(10 + 20)? Answer it yourself first. Ready? Click to check.

print("10 + 20") shows 10 + 20. The quotes make it text, so Python prints the characters exactly as typed.

print(10 + 20) shows 30. Without quotes these are numbers, so Python calculates first and then prints the result.

2Variables

Goal: understand how programs store information.

Definition

A variable is a name that refers to a value stored in the computer's memory. You create one with =, which is called assignment:

name = value. Python works out the right-hand side, then attaches the name on the left to it.

In Python, = doesn't mean "equals" the way it does in maths. Read it as "gets" or "now refers to". age = 17 means "age now refers to 17".

Try thisname = "Punith"
age = 17
marks = 85

print(name)
print(age)
print(marks)
OutputPunith
17
85

Changing a value

Assign again and the name moves to the new value. The old value is forgotten.

age = 17
age = 18
print(age)        # 18

Rules for naming variables

Rule✅ Allowed❌ Not allowed
Only letters, digits and underscore _total_markstotal-marks, my marks
Can't start with a digitmarks11marks
Can't be a Python keywordclass_nameclass, if, for
Case-sensitiveAge and age are two different variables

Good habit: use names that say what the value is. maths_marks is better than m or x.

What happens if you change the value of age to 18? Answer it yourself first. Ready? Click to check.

Write age = 18 and the name age now refers to 18. Every print(age) after that line prints 18. Lines that ran earlier have already printed 17, because Python runs from top to bottom. That's why it's called a variable: its value can vary.

What is the difference between 17 and "17"? Answer it yourself first. Ready? Click to check.

17 is an int, a number you can do maths with. "17" is a str, just the two characters 1 and 7.

Look at what + does to each:

print(17 + 3)       # 20      → adds numbers
print("17" + "3")   # 173     → joins text
print("17" + 3)     # TypeError: can't add text and a number

4Taking user input: input()

Goal: make programs interactive.

Definition

input("message") shows the message, waits for the user to type something and press Enter, then gives back what they typed. It always gives back a str, even if the user typed digits.

To do maths with what the user typed, convert it:

  • int("17") → 17, a whole number
  • float("5.8") → 5.8, a decimal number
Try thisname = input("What is your name? ")
age = int(input("How old are you? "))

print("Hello", name)
print("You are", age, "years old")
Sample run (what the user types is after the ?)What is your name? Punith
How old are you? 17
Hello Punith
You are 17 years old

Read int(input("How old are you? ")) from the inside out: first input gets the text "17", then int turns it into the number 17, then = stores it in age.

Why do we use int() when accepting someone's age? Answer it yourself first. Ready? Click to check.

Because input() always returns text. Without int(), age would be the string "17", and something like age + 1 would crash with a TypeError. int() converts it into a real number so Python can calculate with it.

What is the difference between /, // and %? Answer it yourself first. Ready? Click to check.

Think of sharing 15 sweets among 4 friends:

  • 15 / 4 → 3.75: the exact answer, as a decimal.
  • 15 // 4 → 3: each friend gets 3 whole sweets.
  • 15 % 4 → 3: 3 sweets are left over.

Check: 4 × 3 + 3 = 15 ✔. So // and % always go together.

Part 2 · Today's main assignment

🎯 Project · Student Report Card Generator

Your school has asked you to build a program that calculates a student's marks automatically and prints a report card.

Requirements

Your program must:

  1. Ask the student for their name.
  2. Ask for their class.
  3. Ask for their school name.
  4. Ask for marks in Mathematics, English and Science, each out of 100.
  5. Calculate the total marks out of 300.
  6. Calculate the percentage.
  7. Display the report card neatly.

Expected output

Your program should behave something like this:

Rules
  • Use all five concepts from today.
  • Don't type in the total or the percentage yourself. The program must calculate them.
  • It must work for any student and any marks, not just the sample above.
  • Write the code yourself. This page shows no solution, on purpose.

Stuck? Open one hint at a time

Hint 1 · Plan before you type

Write the program as three blocks: input (ask for everything), process (calculate), and output (print the card). Which of today's five concepts does each block need?

Hint 2 · Which inputs need converting?

You'll never do maths with the name, class or school. You will do maths with the marks. Look back at Concept 4: which ones need int()?

Hint 3 · Calculating the percentage

If you scored 45 out of 50, how would you work out your percentage on paper? Write that calculation using Python's operators and your variable names.

Hint 4 · The % sign after the percentage

Inside print, the % sign is just text. Where does text go? And remember that commas in print add a space. Try it and see if that space bothers you.

Hint 5 · The ===== lines

Typing 33 = signs works. But what do you think "=" * 33 gives? Try it in Python.
