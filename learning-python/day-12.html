Binary search

Search a sorted list by repeatedly keeping only the half that can contain the target.

The program

Download .py
01def binary_search(list, ele):
02    n = len(list)
03    first = 0
04    last = n - 1
05    while first <= last:
06        mid = (first + last) // 2
07        if ele == list[mid]:
08            return mid
09        elif ele < list[mid]:
10            last = mid - 1
11        else:
12            first = mid + 1
13    return None
